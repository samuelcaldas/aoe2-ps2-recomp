# Desktop Probe Runtime Linkage Root-Cause Audit

## 1. Scope & Non-Goals

### 1.1 Scope
This document provides a strictly read-only, factual root-cause audit of the linker failures encountered during the desktop compilation probe of the authoritative PS2Recomp output for **Age of Empires II: The Age of Kings** (PS2 PAL `SLES-50282`).

The investigation answers whether unresolved symbols (such as `Store128`, `dispatchGuestBranch`, `Read128`, and `g_ps2RecompiledFunctionTableSlotCount`) stem from:
1. An incomplete or unlinked PS2Recomp runtime target;
2. A missing generated registration/table source file;
3. An ABI/signature mismatch;
4. Library order / `--as-needed` linker behavior; or
5. An incorrect CMake/Ninja link command.

### 1.2 Non-Goals
* No source code modifications to PS2Recomp, the target ELF, Ghidra export, or generated C++ files.
* No changes to third-party lockfiles or dependency revisions.
* No introduction of speculative stubs, placeholder return codes (`ret0`/`ret1`/`reta0`), or instruction patches.
* No guest code execution or emulation bring-up.

### Finding 1: `ps2_runtime` Target Is Absent From Built Libraries
In `third_party/PS2Recomp/build/CMakeCache.txt`, the recompiler toolchain was configured with `PS2X_BUILD_RUNTIME:BOOL=OFF` (as required for building the headless code generator `ps2_recomp` without installing host multimedia libraries `raylib` and `ffmpeg`). Consequently, no static runtime library (`libps2_runtime.a`) exists on disk.

## 4. Source & Symbol Analysis

### 4.1 Generic Runtime Methods (`Store128`, `dispatchGuestBranch`)
* **Source Location**: `third_party/PS2Recomp/ps2xRuntime/src/lib/ps2_runtime.cpp`:
  - `void PS2Runtime::Store128(uint8_t *rdram, R5900Context *ctx, uint32_t vaddr, __m128i value)` (line 2134)
  - `bool PS2Runtime::dispatchGuestBranch(...)` (line 1345)
* **Symbol Signature**: Exact match for the mangled callsites generated by `ps2_recomp` in generated `.cpp` files.
* **Link Command Status**: Neither `libps2_runtime.a` nor `ps2_runtime.cpp.o` is supplied in the link command of `desktop_runtime_probe`.
* **Classification**: `runtime_target_not_linked`.

### 4.2 Function Table Glue (`g_ps2RecompiledFunctionTableSlotCount`)
* **Generated Location**: `generated/SLES-50282/register_functions.cpp` (32.4 MB, generated by `ps2_recomp` during the authoritative pipeline run).
  ```cpp
  extern const uint32_t g_ps2RecompiledFunctionTableBase = 0x100008u;
  extern const uint32_t g_ps2RecompiledFunctionTableEnd = 0x4d6fecu;
  extern const uint32_t g_ps2RecompiledFunctionTableSlotCount = 1006585u;
  PS2Runtime::RecompiledFunction g_ps2RecompiledFunctionTable[1006585u] = {};
  ```
* **Build Target Discrepancy**:
  In `CMakeLists.txt`, `file(GLOB GENERATED_CPP_SOURCES "${GENERATED_SRC_DIR}/*.cpp")` captures `register_functions.cpp`, but `CMakeLists.txt` also explicitly appends `"${PS2X_RUNTIME_DIR}/src/runner/register_functions.cpp"`.
  The upstream runner contains a duplicate conflicting table definition (`g_ps2RecompiledFunctionTableBase = 0x00000000u`), resulting in multiple definition collisions if linked together, while in single-file probe links `generated/SLES-50282/register_functions.cpp.o` was not linked.
* **Classification**: `generated_registration_source_omitted`.

## 6. Root-Cause Conclusion & Recommended Next Step

### 6.1 Root Cause
The unresolved symbol diagnostics in the minimal desktop probe are **not** caused by generated code bugs, toolchain ABI mismatches, or missing MIPS recompilation output. They are factually caused by two distinct linkage factors:
1. **Unlinked Runtime Target**: The generic `PS2Runtime` method implementations (`Store128`, `dispatchGuestBranch`, memory accessors) exist in `third_party/PS2Recomp/ps2xRuntime/src/lib/ps2_runtime.cpp`, but no runtime library is linked into the desktop probe because `PS2X_BUILD_RUNTIME=OFF` was configured to avoid host dependencies (`raylib`/`ffmpeg`).
2. **Registration Glue Redundancy/Omission**: The recompiler generated `generated/SLES-50282/register_functions.cpp` containing the authoritative function table and slot count (`1006585u`), but `CMakeLists.txt` also included the placeholder `ps2xRuntime/src/runner/register_functions.cpp`, creating a symbol collision or omission in the link command.

### 6.2 Recommended Next Task
**Generic Runtime API Implementation Plan (Headless Minimal Runtime Abstraction)**:
Before attempting a full desktop link, define a minimal, clean-room runtime backing layer (or build a headless subset of `ps2xRuntime`) providing `Store128`, `Read128`, `dispatchGuestBranch`, and memory mappings without pulling in desktop GUI/multimedia dependencies (`raylib`, `ffmpeg`). Concurrently, correct `CMakeLists.txt` to strictly link `generated/SLES-50282/register_functions.cpp` while removing the duplicate upstream runner placeholder.
